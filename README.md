# What is it?
Script I made to check whether a pump.fun coin is actually on the bonding curve it claims to be on, if the coin's own trades disagree on `k` then it isn't, that's arithmetic and not a model, it tells you what is there and never that a coin is safe

## Install
`python3 curve_check.py <mint>`

One file, standard library only, read the whole thing in five minutes before you run it. App for mac and windows on the [releases page](https://github.com/Cadaquesenc/curve-check/releases), unsigned so both will warn you.
